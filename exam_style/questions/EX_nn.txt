Gradient descent is run on E(w) = (1/2) w^2, so dE/dw = w and each step is w <- w - eta w = (1 - eta) w. The start is w = 1. For which learning rates is |w| strictly smaller after every single step? (Select one or more.)

--- stem
Why can a unit with a hard step (threshold) activation not be trained directly by gradient descent on a loss?
--- A*
Its slope is zero almost everywhere and undefined at the jump, so the gradient gives no direction
>> Correct: the step function is flat except at the jump, so a small change in a weight changes the loss by nothing. This is why the course replaces it by the smooth sigmoid.
--- B
Its output is bounded between two values, and gradient descent needs outputs that are unbounded above
>> Wrong: the sigmoid is also bounded (0 to 1) and works. Boundedness is not the problem, flatness is.
--- C
It has too many weights to store, since each step unit needs one weight for every training example
>> Wrong: a step unit has one weight per input (plus a bias), the same as any other unit.
--- D
It can only be used with a single input, so gradient descent cannot be applied to it at all
>> Wrong: a step unit (perceptron) can have many inputs. The issue is the shape of its activation.
--- explain
Gradient descent follows the slope of the loss with respect to each weight. For a step activation the slope is 0 almost everywhere (and undefined at the jump), so it carries no information. A smooth activation such as the sigmoid has a useful slope everywhere.
