--- stem
A fraud detector is tested on 200 transactions, with fraud as the positive class. It flags 45 frauds correctly (TP), misses 15 frauds (FN), wrongly flags 10 genuine transactions (FP) and correctly passes 130 genuine ones (TN). What is its recall (true positive rate)?
--- A*
0.7500
>> Recall = TP / (TP + FN) = 45 / 60 = 0.75: of the real frauds, the share that was found.
--- B
0.8182
>> This is the precision, 45 / (45 + 10) = 0.8182. Precision divides by everything flagged, not by everything that is really positive.
--- C
0.9286
>> This is the specificity, TN / (TN + FP) = 130 / 140. It describes the genuine transactions, not the frauds.
--- D
0.8750
>> This is the accuracy, (45 + 130) / 200. It counts the true negatives as well, which recall never uses.
--- explain
Recall divides the true positives by all actual positives: 45 / (45 + 15) = 45 / 60 = 0.7500. The other three options are precision (0.8182), accuracy (0.8750) and specificity (0.9286) computed from the same counts.

--- stem
A new test kit is tried on 60 people who are all known to be infected (the positive class). The kit returns a positive result for 45 of them. Using only the results on this group, which of the following can be calculated? (Select one or more.)
--- A*
The number of false negatives (15)
>> Everyone in the group is truly infected, so each of the 60 people either is found (TP = 45) or missed (FN = 15). The count of misses is simply 60 - 45 = 15.
--- B
False positive rate
>> FPR = FP / (FP + TN) needs actual negatives. The group has none, so FP + TN = 0 and the rate is undefined.
--- C
Specificity
>> Specificity = TN / (TN + FP) also divides by the number of actual negatives, which is 0 here, so it is undefined.
--- D*
Recall (0.75)
>> All 60 are actual positives, so TP = 45 and FN = 15, and recall = 45 / 60 = 0.75.
--- explain
With no actual negatives in the group, FP = 0 and TN = 0. Everything that involves only the actual positives can be computed: TP = 45, FN = 15 and recall = 45/60. Metrics that divide by the actual negatives (FPR, specificity) are 0/0.

Of 1000 patients, 20 are truly sick. A lazy classifier predicts "healthy" for every patient. With "sick" as the positive class, what are its accuracy and recall?

--- stem
A logistic regression model scores each test example. The decision threshold is lowered from 0.7 to 0.4, so more examples are predicted positive. Which of the following MUST hold? (Select one or more.)
--- A
The precision does not decrease.
>> Precision can go either way: the newly flagged examples may be mostly negatives, which lowers TP / (TP + FP).
--- B*
The TPR does not decrease.
>> Every example flagged at 0.7 is still flagged at 0.4, so TP can only stay the same or grow, and TPR = TP / P does too.
--- C*
The FPR does not decrease.
>> The set of flagged examples only grows, so FP can only stay the same or grow, and so does FPR = FP / N.

The AUC increases.
>> AUC summarises the whole curve over all thresholds, so moving the threshold only moves along the same ROC curve and leaves AUC unchanged.
--- explain
Lowering the threshold flags a superset of examples. TP and FP can only rise or stay put, so TPR and FPR cannot fall. Precision is a ratio of the two and can rise or fall. AUC does not depend on any single threshold.
