For a single parameter theta, the squared-error part of the cost is (theta - 5)^2. Ridge adds lambda * theta^2 and LASSO adds lambda * |theta|. With lambda = 2, what are the minimising values of theta for the ridge cost and for the LASSO cost?
--- A*
Ridge 1.6667, LASSO 4.0000
>> Ridge: 2(theta - 5) + 2 * lambda * theta = 0 gives theta = 5/(1 + lambda) = 5/3. LASSO: 2(theta - 5) + lambda = 0 gives theta = 5 - lambda/2 = 4.
--- B
Ridge 4.0000, LASSO 1.6667
>> The two formulas are swapped. Ridge divides by (1 + lambda) and LASSO subtracts lambda/2.
--- C
Ridge 2.5000, LASSO 4.0000
>> The ridge value 2.5 is 5/(1 + lambda/2). The ridge derivative has 2 lambda theta, so the divisor is 1 + lambda = 3.
--- D
Ridge 1.6667, LASSO 3.0000
>> The LASSO value 3 is 5 - lambda. The derivative of lambda * |theta| is lambda (for theta > 0), and the square contributes a 2, so theta = 5 - lambda/2.
